# Menzio Store

واجهة أولية لمتجر Menzio للملابس الداخلية الرجالية.

## الحالة الحالية
- صفحة رئيسية متجاوبة مع الهاتف.
- قسم منتجات تجريبي.
- سلة مشتريات تعمل محليًا في المتصفح.
- تصميم RTL باللغة العربية.

## المتبقي قبل الإطلاق
- استبدال المنتجات التجريبية بالمنتجات والصور والأسعار الحقيقية.
- إضافة المقاسات والألوان والمخزون.
- إنشاء نموذج طلب حقيقي وبيانات التوصيل داخل الجزائر.
- اختيار وربط طريقة الدفع المناسبة.
- إضافة سياسة الخصوصية والاسترجاع والشروط.
- اختبار نهائي على الهاتف ثم نشر الموقع.
